Universal Learning Tracker

Your personal learning and productivity dashboard.

Universal Learning Tracker is an Android learning application built with Python and Kivy. It helps users organize their learning, monitor progress, build consistent study habits, and track personal development.

Features

- Learning Dashboard: View subjects, completed tasks, and study time.
- Subject Management: Create and manage different learning subjects.
- Task Tracker: Add learning tasks and monitor completion.
- Study Timer: Track focused learning sessions.
- Personal Notes: Write and save notes under each subject.
- Learning Calendar: Review your study history.
- Daily Goals: Set daily study targets.
- Weekly Analytics: Monitor your learning activity.
- Achievements: Celebrate milestones and maintain consistency.

Technology

- Python 3
- Kivy Framework
- SQLite Database
- Buildozer
- GitHub Actions

Android Application

This project is designed to be packaged as an Android APK.

Project Goal

To provide a simple, practical, and universal platform that helps people learn new skills, stay organized, measure progress, and achieve continuous personal growth.

Learn. Track. Improve. Repeat.
